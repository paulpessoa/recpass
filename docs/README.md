**Uma frase:** *substituir barreiras de pedra por pontes de dados*. Tags NFC discretas no mobiliário do Bairro do Recife dão contexto ao celular (onde estou, o que está lotado, por onde passa uma cadeira de rodas), e um agente ajuda a decidir o próximo passo.
